
APE 5 – Manejo de archivos en Java

Estudiante: Esteban Zambrano

Carrera: Ingeniería en Software

Universidad: Universidad Técnica de Ambato

Actividad: APE 5 – Primera parte

Descripción

Desarrollo de tres ejercicios prácticos en Java relacionados con el manejo de archivos de texto.

Ejercicios realizados

Ejercicio 1: Crear un fichero

* Crear el archivo curso.txt.
* Comprobar si el archivo existe.
* Mostrar el nombre del archivo.
* Controlar errores mediante try-catch.

Ejercicio 2: Escribir información en un fichero

* Ingresar un mensaje mediante Scanner.
* Utilizar FileWriter para escribir información.
* Conservar el contenido anterior mediante el parámetro true.
* Guardar y cerrar el archivo.

Ejercicio 3: Eliminar un fichero

* Crear un objeto File.
* Utilizar el método delete().
* Comprobar si el archivo se eliminó correctamente.
* Mostrar un mensaje de confirmación.

Herramientas utilizadas

* Lenguaje de programación Java.
* IDE de desarrollo.
* Clases File, Scanner y FileWriter.

Objetivo

Aplicar los conocimientos de programación en Java mediante la creación, escritura y eliminación de archivos de texto, utilizando clases, métodos y manejo de excepciones.
